
# Compakt Mirror

## Info

Simple mirror application using built-in or installed camera, with capture feature. 
This is a javafx maven project and also using webcam-capture library.
No problem compiling and building this on windows and linux, but haven't tried on mac.
Maybe someday 😃

## Install

Choose a link for your distribution and click to download.

Linux:

[compakt-mirror_v1.0_linux.tar.xz](https://github.com/doroyg/compakt-mirror/releases/download/v1.0/compakt-mirror_v1.0_linux.tar.xz)

[compakt-mirror_v1.0_linux_jre-bundle.tar.xz](https://github.com/doroyg/compakt-mirror/releases/download/v1.0/compakt-mirror_v1.0_linux_jre-bundle.tar.xz)

Windows:

[compakt-mirror_v1.0_windows.7z](https://github.com/doroyg/compakt-mirror/releases/download/v1.0/compakt-mirror_v.10_windows.7z)

[compakt-mirror_v1.0_windows_jre-bundle.7z](https://github.com/doroyg/compakt-mirror/releases/download/v1.0/compakt-mirror_v1.0_windows_jre-bundle.7z)

Extract the downloaded file to your preferred directory. For Linux distro, make sure to make 'mirror.sh' executable. And for Windows, just double click the 'mirror.bat' file to run the application. Download file with 'jre-bundle' in the name if your machine doesn't have java installed.

## How To

When choosing from multiple webcams, 'alt' key or right mouse click to show context menu. 
To capture image, click the middle mouse button or 'c' key,
and for the delayed capture, press 'v' key with 5 seconds waiting time. 
'Esc' key to close application.
